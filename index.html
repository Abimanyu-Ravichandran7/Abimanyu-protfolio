Project 01 · Full-stack platform · Live

Qaroo India — CMS-Driven Web Platform

Overview

A full-stack, CMS-driven web application for Qaroo India Private Limited. It turns the React + Vite public site into a content-managed platform backed by a new Node.js, Express and MongoDB API, so the site's pages, MOU directory, CSR projects and learning programs are all edited from an admin dashboard at /admin.

Admins sign in with JWT access and refresh tokens stored in HTTP-only cookies, verify their email, and need Super Admin approval before they can act. Every change is guarded by granular, role-based permissions, while public visitors only ever see published content.

Key features

  • Public site powered by the CMS
  • Admin dashboard with overview stats
  • Editable page content
  • MOU directory management
  • CSR project management
  • Learning program management
  • Contact message inbox
  • Granular role-based permissions
  • Super Admin approval workflow
  • JWT auth in HTTP-only cookies
  • Email verification & password reset
  • Cloudinary image uploads
  • API rate limiting
  • Frontend crash reporting
  • End-to-end API test suite

Project 02 · Full-stack platform · TypeScript

Institute OS — Institute Management & Placement Platform

Overview

A course-institute management, business-intelligence and placement platform that covers the full student lifecycle: enquiries with source tracking, admissions, fees and receipts, batches and trainers, classes, attendance, online exams, study material and certificates, through to technical and non-technical placement.

The side navigation follows the login — owner/admin, counsellor, office staff, faculty or student — and each role gets its own permissions, menu and home page. It is a TypeScript monorepo (shared, server and client workspaces) with a 34-table SQLite schema managed by Drizzle ORM and integration tests that run against an in-memory database.

Key features

  • Leads with source & campaign tracking
  • Kanban pipeline & follow-up calendar
  • Admissions with flexible fee plans
  • Fee ledger, PDF receipts & refunds
  • Batches, trainers & transfers
  • Class schedule with clash checks
  • Attendance registers
  • Online exams graded on the server
  • Certificates with public verification
  • Student portal & faculty workspace
  • Placement drives, interviews & offers
  • Leave, tasks & asset inventory
  • KPI dashboards with drill-down
  • PDF/Excel reports & scheduled email
  • Staff permissions & audit trail

Project 03 · Full-stack app · React + Django

StockMaster — Online Product Inventory & Order Tracker

Overview

A full-stack inventory and order-tracking system with a dark-themed React frontend and a Django REST Framework backend. Admins manage products, categories and orders from a live dashboard; customers browse products, build a cart, place orders and follow each order's progress.

Authentication uses JWT access and refresh tokens, with an Axios interceptor that renews the session silently on a 401. Placing an order automatically deducts stock, and admin-only endpoints are protected by role.

Key features

  • JWT auth with auto-refresh
  • Admin dashboard with live stats
  • Low-stock alerts & recent orders
  • Searchable, paginated product table
  • Product images & stock badges
  • Category hierarchy (parent/child)
  • Admin order status updates
  • Customer cart with live totals
  • Stock deducted on order
  • Step-by-step order tracker
  • Role-protected REST API
  • Responsive grid layouts

Technology

Project 04 · Internal project

CRM Web Application

Overview

A comprehensive CRM web application for an institute offering supplementary and skill-based education. It brings enrollment, staffing, attendance, testing, syllabus and task workflows into one place, with intuitive dashboards that simplify daily academic and administrative processes.

Data lives in a structured MySQL database for secure, reliable storage and retrieval of student records, staff details, attendance logs, test results and task updates. Overview
